# 🚲 Ford GoBike Data Visualization

Exploratory and explanatory analysis of Ford GoBike trip data using Python, pandas, Matplotlib, and Seaborn.

## 📌 Project Overview

This project explores bike-sharing behavior in the Ford GoBike System using data from February 2019.

The analysis focuses on understanding typical trip behavior and examining how trip duration differs between Customers and Subscribers.

The project includes two parts:

1. **Exploratory Analysis** — investigating patterns and relationships in the data
2. **Explanatory Visualization** — presenting the most important findings clearly through visualizations

## 📊 Dataset

The dataset contains **183,412 bike trips** recorded in the San Francisco Bay Area during February 2019.

The data includes information such as:

- Trip duration
- Start and end stations
- User type
- Rider birth year
- Gender
- Trip times

## 🔍 Questions Explored

- What does the distribution of trip duration look like?
- Who uses the service more: Customers or Subscribers?
- Do Customers and Subscribers have different trip durations?
- How do age and gender relate to trip behavior?

## 📈 Key Findings

- Most Ford GoBike trips were relatively short, with many trips lasting less than approximately 15 minutes.
- Subscribers accounted for the large majority of recorded trips.
- Customers generally took longer trips than Subscribers.
- Customer trip durations showed greater variation.
- Rider age did not show a strong relationship with trip duration.
- Differences between Customers and Subscribers were more noticeable than differences associated with age or gender.
